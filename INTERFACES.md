# Frozen v0 interfaces (2026-10-05)

Python >=3.10, dependency-free core. Package name `foldcontract`; version `0.1.0a1`.
Input JSON exact fields: `version: 1`, `groups: [str]`, `classes: [str]`, `partitions: [str]`, `counts: [[int]]`, `requirements: [{id: str, partition: str, measure: "class"|"records"|"groups", class: str (only for class), lower: int (optional default0), upper: int (optional default total)}]`.
At least one of lower/upper required. Repeated measures conjunctive, names distinct. Reject unknown fields.
Input limits:4MiB, depth6, integer token10digits, 128groups,32classes,8partitions,1024requirements,128byte IDs,total records1e9; at least1class/group,2partitions. Bounds int0..1e9 even if outside available totals or inverted.

`model.py`: `ValidationError(ValueError)` with code/message; frozen `Requirement(id, partition, measure, class_name, lower, upper)` where partition/class_name are names; frozen `Problem(groups:tuple[str], classes:tuple[str], partitions:tuple[str], counts:tuple[tuple[int]], requirements:tuple[Requirement], digest:str)`. Canonical order lexicographic exact IDs (groups/classes/partitions/requirements); matrix permuted. `parse_problem(data:bytes|str)->Problem`, `problem_from_dict(value:dict)->Problem`, `problem_to_dict(problem)->dict`, `with_requirements(problem, ids:Iterable[str])->Problem`. No semantic hidden requirements.
`checker.py`: independent no-solver `check_assignment(problem, assignment:list[dict] | dict[str,str])->dict` returns `{valid:bool, violations:[{...}], totals:...}`. Each entry `{group:str, partition:str}`; duplicate/missing/extra/unknown rejects. `check_report(problem, report:dict)->dict` accepts only FEASIBLE+matching `problem_digest` and checks raw assignment.
`solver.py`: `solve(problem, *, max_nodes=100000, deadline:float|None=None)->dict` using monotonic deadline; returns `{status, reason, problem_digest, assignment:[{group,partition}] when feasible, nodes:int, engine_version:"0.1.0a1"}`; node count increments once per search-state before propagation; max_nodes0 UNKNOWN even trivial. No wall deadline by default in low-level core. FEASIBLE independently checked before returned. No ERROR swallowed into UNKNOWN. ValidationError for invalid budgets.
`explain.py`: `explain(problem, *, max_nodes=100000, max_checks=1024, deadline=None)->dict`. First establishes original solve then if INFEASIBLE reduces within max_checks using shared total node budget (original and reduction); preserve INFEASIBLE across incomplete reduction. Explanation `{requirement_ids, minimal:bool, complete:bool, checks, removal_witnesses:[{removed,assignment}], reason}`; minimal only all final removal witnesses checked against final reduced problem. No generic proof claim.
`adapter.py`: `aggregate_rows(y,groups,partitions,requirements=())->Problem` strings only labels/group IDs; `kfold_problem(y,groups,n_splits=5,min_class_count=1)->Problem` explicitly adds class and group minima. `split_indices(problem,report,y,groups)->list[(train_indices:list[int],test_indices:list[int])]` validates counts and group mapping, rejects empty test/train; does not require sklearn import.
`runtime.py`: `run_bytes(data:bytes, *, operation="solve", max_nodes=100000, timeout=10.0, memory_mb=512, max_checks=1024)->dict` supervised bounded worker and parent independently checks FEASIBLE. Validate/solve/explain. Malformed input returns VALIDATION_ERROR, unexpected failure ERROR, resource budget UNKNOWN only known. All enforcement scopes exposed truthfully; explicitly no absolute publication deadline promise. Node-only core remains available without hard memory limits. No arbitrary imported callbacks/protocol pickle.
`cli.py`: commands validate/solve/explain/check. `foldcontract solve INPUT [--output FILE] [--max-nodes N] [--timeout SECONDS] [--memory-mb MB]`; check INPUT REPORT. Exit0 FEASIBLE/valid/VALID,2 INFEASIBLE,3UNKNOWN,4validation/check-invalid,5ERROR. Output no-clobber atomic link/rename semantics never overwrite input/output.
